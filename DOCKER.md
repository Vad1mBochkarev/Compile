# Шпаргалка по командам Docker Compose

## Сборка и запуск

* `docker compose up` — создать и запустить все контейнеры с выводом общих логов в консоль.
* `docker compose up --build` — пересобрать образы из `Dockerfile` и запустить все сервисы.
* `docker compose up -d` — запустить все сервисы в фоновом режиме (`detached`).
* `docker compose up -d --build` — пересобрать образы и сразу запустить в фоне.
* `docker compose build` — только собрать или пересобрать образы без запуска контейнеров.
* `docker compose pull` — скачать свежие версии готовых образов (например, `postgres`).

## Остановка и удаление

* `docker compose stop` — остановить запущенные контейнеры, но не удалять их.
* `docker compose start` — снова запустить ранее остановленные контейнеры.
* `docker compose restart` — перезапустить все сервисы (или `docker compose restart <сервис>` для одного).
* `docker compose down` — остановить и удалить контейнеры и созданную сеть (данные в `volume` сохраняются).
* `docker compose down -v` — остановить и удалить контейнеры, сеть **и все `volume`** (полная очистка БД).

## Просмотр статуса и логов

* `docker compose ps` — показать список сервисов проекта, их статус и проброшенные порты.
* `docker compose logs` — вывести историю логов всех контейнеров.
* `docker compose logs -f` — смотреть логи всех сервисов в реальном времени.
* `docker compose logs -f <сервис>` — смотреть логи конкретного сервиса в реальном времени (например, `backend`).

## Выполнение команд внутри контейнера

* `docker compose exec <сервис> <команда>` — выполнить команду внутри работающего контейнера.
  * `docker compose exec db psql -U compile_user -d compile_db` — зайти в консоль PostgreSQL внутри контейнера `db`.
  * `docker compose exec backend sh` — открыть терминал внутри контейнера `backend`.

## Полезные команды базового Docker

* `docker ps` — показать все запущенные сейчас контейнеры на компьютере (`docker ps -a` — включая остановленные).
* `docker images` — показать список всех скачанных и собранных образов.
* `docker volume ls` — показать список всех томов (`volumes`) для хранения данных.
* `docker system prune` — удалить неиспользуемые контейнеры, сети и кэш образов для освобождения места.
